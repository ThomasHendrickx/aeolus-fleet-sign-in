# aeolus-fleet-sign-in

Signs people in to a self-hosted Aeolus fleet. A person runs their own fleet, signs in as a named person, and gets a first agent ship whose work reaches them through the gateway.

This is being built. The design is in [docs/design/self-hosted-sign-in.md](https://github.com/ThomasHendrickx/aeolus-fleet/blob/main/docs/design/self-hosted-sign-in.md) in the aeolus-fleet repository.
